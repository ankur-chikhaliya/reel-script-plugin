# Reel Script Writer

Write short-form video scripts built for retention — every line earns the next second of watch time.

## Step 1: Get the essentials

Don't ask what's already given. Ask only what's missing, one short message, skip fields that don't apply:

1. **Topic**. If none at all given, don't just ask "what's it about?" — offer in the same message: "Or I can find trending ideas for your niche first." If taken, hand off to `reel-trends` Step 1.
2. **Goal** — sell, teach, entertain, or grow. Default: whatever topic implies.
3. **Language** — match the user's language. English + mentioned region (e.g. Indian audience) → offer local language/mix (Hinglish) as an option. Write natural spoken style for that locale, not literal translation — hooks translated word-for-word usually fall flat. Hashtags stay Roman script regardless (that's how people search).
4. **Length** — default 30s (under 35s rewatches more).
5. **Link/handle** (optional, any content type not just business) — ask only if goal points somewhere.
6. **Response method** (optional: DM word, comment word, email, phone, link in bio) — ask only if goal needs a concrete action.

## Step 2: Write the script

### 🎬 [Title]
**Topic:** … | **Goal:** … | **Length:** …s | **Language:** … *(+ Link/Response if given)*

#### Hook options (3, different angles)
Curiosity gap · Bold claim/contrarian · Direct callout · Result first · Question that stings · Pattern interrupt (open mid-action, confusion buys a second) · Loss aversion · Social proof cold open.
**Rule:** specificity beats vague — a number/timeframe/named detail ("in 9 days," "₹200") beats the generic version. Applies to CTA wording too.

#### Script beats
| Time | Voiceover | On screen |
|------|-----------|-----------|
| 0–2s | (hook) | (matching visual) |

- Change something on screen every 3–5s — static = swipe.
- Spoken language, short lines — read aloud test.
- Most valuable point at ~70% mark, not the start.
- Second-to-last beat opens a loop/tease before CTA.
- Last timestamp = declared Length exactly, no drift.
- No stated-as-fact claims/guarantees/medical-financial-legal content unless user supplied it — general framing + one disclaimer line instead.

#### CTA
One only, matches goal, uses Step 1's response method if given: Grow→follow; Sell→DM/response-method/link-in-bio; Engagement→one-word question; Saves→"save this for when…". No response method + not needed → save/follow line.

#### Caption
First line = second hook. 2–4 lines value/context + CTA repeated (+ link as text). Hashtags 3–8 (big/medium/niche mix) — best-guess, not researched; mention once that `reel-hashtags` Step 1 can swap in a source-backed set instead.

#### Voiceover only
Plain narration text, no timestamps/directions.

## Step 3: One iteration
After delivering: "Want a different angle, hook style, or another language?" — nothing more.

## Example
"reel for my phone store, diwali offer" → 20s Hinglish script: 3 hooks (e.g. "Diwali pe phone lene ka sahi time? Aaj nahi — ye video pehle dekho"), beats table, CTA ("Store ka naam DM karo — offer price bhej dunga"), caption, voiceover block.
